# Design System: Hyosung ITX Slogan Brief
**Project ID:** local-research-brief-2026-06-25

## 1. Visual Theme & Atmosphere
Operational, credible, and technology-forward. The document should feel like an executive research brief rather than a campaign mood board: compact evidence, calm hierarchy, and clear decision framing. The emotional tone is practical confidence: Hyosung ITX is presented as a company that already runs customer-facing operations at scale and is now adding AI, cloud, and ITO capability to that operating base.

## 2. Color Palette & Roles
- **Deep Operations Navy (#1F2A44):** Primary title and section band color. Signals trust, B2B reliability, and enterprise operations.
- **Hyosung Accent Red (#C9152E):** Sparingly used for the final slogan recommendation and key decision markers. This is a campaign accent, not a full-page background.
- **Cloud Gray (#EEF2F5):** Light table header and evidence-card background. Keeps dense financial and disclosure data readable.
- **Ink Black (#111827):** Main body copy for high contrast.
- **Muted Evidence Gray (#6B7280):** Source notes, dates, and caveats.

## 3. Typography Rules
Use a conservative sans-serif document style. Titles are bold and compact; body copy is 10.5-11 pt with steady line spacing. Avoid decorative type treatments. Korean and English terms should sit naturally in the same paragraph, with English abbreviations preserved only when they are source terms such as AI, ITO, IDC, AICC, and DART.

## 4. Component Stylings
* **Buttons:** Not applicable. This is a static executive document.
* **Cards/Containers:** Use flat shaded rows or callout tables with sharp, low-radius implied edges. No heavy shadows.
* **Inputs/Forms:** Not applicable.
* **Evidence Tables:** Header rows in Cloud Gray (#EEF2F5), dark text, thin neutral borders. Numerical claims should be grouped by source date.
* **Recommendation Callout:** A single Deep Operations Navy block with Hyosung Accent Red emphasis for the selected slogan.

## 5. Layout Principles
Start with the decision, then show evidence. Keep each page scannable: one main argument per section, tables for hard numbers, short rationale paragraphs for interpretation. The slogan section should be visually distinct from the analysis section so the reader can move from research to creative decision without losing the evidence chain.
