# 효성ITX 슬로건 제안서 추가 자료 요청서

자료 기준일: 2026-06-25

## 1. 목적

앞선 공개 리서치만으로는 효성ITX의 신규 슬로건 방향을 가설 수준까지 잡을 수 있다. 다만 최종 제안서는 광고·마케팅 문구이므로, 표현의 매력보다 먼저 확인해야 할 것이 있다. 슬로건이 실제 사업 역량을 정확히 말하는지, 경쟁사 문구와 구별되는지, 법무·상표·표시광고 리스크가 없는지, 내부 구성원이 받아들일 수 있는지다.

이 문서는 슬로건 제안서 작성 전에 효성ITX 내부에서 추가로 받아야 할 자료를 정리한다. 기준은 컨택센터·IT 서비스·AI 운영 표준과 B2B 브랜드·마케팅 표준을 함께 적용했다.

## 2. 현재 공개 자료로 가능한 것과 부족한 것

| 구분 | 가능한 판단 | 부족한 판단 |
|---|---|---|
| 기업 분석 | 컨택센터, IT Service, Display Solution을 주요 사업 축으로 보는 방향은 확인 가능 | 회사가 2026년 이후 어느 사업을 브랜드 중심축으로 밀지 확인 필요 |
| 특수 관계 분석 | 효성그룹 계열 구조와 특수관계자 보유 구조는 공시로 확인 가능 | 그룹 브랜드를 슬로건에서 어느 정도 활용할지 내부 원칙 필요 |
| 사업 분석 | 컨택센터 매출 비중이 크고 AI·ITO·IDC가 확장 영역이라는 점은 확인 가능 | 고객 성과, SLA, 운영 품질, AICC 도입 효과 등 실증 자료 필요 |
| 공시 분석 | 매출, 배당, 기업가치 제고 계획 등 신뢰 신호는 확인 가능 | 슬로건에 쓸 수 있는 정량 claim의 내부 승인 범위 필요 |

## 3. 적용할 표준과 프레임워크

| 기준 | 슬로건 개발에서 쓰는 방식 | 추가로 필요한 자료 |
|---|---|---|
| ISO 18295-1/2 | 컨택센터 서비스 품질과 운영 체계를 확인 | 컨택센터 운영 규모, KPI, QA, 상담 품질, 고객사 SLA |
| ISO/IEC 20000-1 | IT 서비스가 프로젝트가 아니라 관리되는 서비스인지 확인 | 장애·변경·문제관리, SLA, ITSM 운영자료 |
| ISO/IEC 27001, ISMS-P | 고객 데이터, 녹취, 권한관리의 신뢰성을 확인 | 보안 인증, 개인정보 처리, 접근권한, 녹취 마스킹 자료 |
| ISO/IEC 42001, NIST AI RMF | AICC·AI claim이 거버넌스를 갖춘 주장인지 확인 | AI 성능관리, 모델 위험관리, 사람개입, 데이터 품질관리 |
| ISO 20671-1, ISO 10668 | 브랜드 평가와 브랜드 가치 관점에서 입력 자료를 정리 | 브랜드 인지도, 연상, 차별성, 선호도, 기존 브랜드 자산 |
| ICC Advertising and Marketing Communications Code | 합법성, 정직성, 진실성 기준으로 문구를 점검 | 수치·우월·혁신·AI 관련 claim의 근거자료 |
| 표시광고법 | 사실 관련 광고 문구의 실증 가능성을 확인 | 최종 후보별 실증자료, 비교광고 근거, 금지 표현 |
| ISO 20252 | 슬로건 테스트 조사의 품질을 관리 | 조사 설계, 표본, 질문지, 결과 보고 방식 |

## 4. High 우선순위 자료

High 자료는 슬로건 방향을 정하기 전에 받아야 한다. 이 자료가 없으면 최종 제안서는 “공개자료 기반 방향안”으로만 표시해야 한다.

| 요청 자료 | 보유 가능 부서 | 필요한 이유 | 미확보 시 대체자료 | 제안서 활용 위치 |
|---|---|---|---|---|
| 브랜드 전략, 비전·미션, 중장기 사업 우선순위 | 경영기획, 전략, 홍보, IR | 슬로건이 회사의 실제 방향과 맞는지 확인 | 기업가치 제고 계획, 사업보고서, CEO 메시지 | 전략 요약, 포지셔닝 |
| 기존 CI/BI 가이드, 기존 슬로건·캠페인 문구, 금칙어 | 홍보, 마케팅, 법무 | 기존 브랜드 자산을 해치지 않고 새 문구를 만들기 위해 필요 | 홈페이지, 회사소개서, 채용공고 | 톤앤매너, 후보 필터 |
| 타깃 고객군과 구매위원회 페르소나 | 영업, 전략, 마케팅 | CEO, CIO, 운영 책임자, 구매 담당자 중 누구에게 말하는지 정해야 함 | 공시 사업부문, 공개 레퍼런스, 영업자료 일부 | 타깃 정의 |
| 산업군별 매출·수주 비중과 전략 고객군 | 영업, 재무, IR | 슬로건이 실제 매출 기반과 성장 시장을 함께 반영해야 함 | 공개 매출 비중, 보도자료 | 핵심 메시지 |
| 컨택센터 운영 규모와 품질 지표 | 고객센터 운영, 품질관리, 사업본부 | “고객 접점”이라는 표현의 실체를 입증 | 공개 운영 규모 문구, 공시 매출 비중 | 근거 장표 |
| VOC, CSAT/NPS, 주요 고객 요구·불만 요약 | 고객센터 운영, 고객지원, 영업 | 고객 언어로 문제를 정의하고 내부 언어를 줄이기 위해 필요 | 익명 고객 후기, 보도자료 | 문제 정의 |
| AICC, RingCloud, xtrmSolution, ITO, IDC 도입 사례 | AI/IT서비스 사업부, PM, 영업 | “지능”, “AI”, “전환” 표현의 실증 근거 | 홈페이지 제품 설명, 특허, 공시 AI 매출 | 솔루션 증거 |
| 고객 성공 사례와 정량 성과 | 영업, 마케팅, 고객사 담당 | “혁신”, “효율”, “전환” claim을 쓸 수 있는 범위 확인 | 익명화 사례, 내부 KPI 구간값 | 후보별 proof point |
| 보안·품질 인증 및 운영 표준 | 보안, 품질, 법무, 운영 | 고객 데이터와 엔터프라이즈 운영 신뢰를 설명 | ISO/ISMS-P 인증서, 심사 범위, 유효기간 | 신뢰성 근거 |
| 상표·법무 검토 제약 | 법무, 홍보, 그룹 브랜드 담당 | 유사상표, 과장광고, 그룹 브랜드 충돌 방지 | KIPRIS 검색, 경쟁사 문구 감사 | 리스크 검토 |

## 5. Medium 우선순위 자료

Medium 자료는 후보안을 설득력 있게 비교하고, B2B 구매 상황에 맞게 다듬는 데 필요하다.

| 요청 자료 | 보유 가능 부서 | 필요한 이유 | 미확보 시 대체자료 | 제안서 활용 위치 |
|---|---|---|---|---|
| 최근 3년 회사소개서, 영업 제안서, IR 자료 | 마케팅, 영업, IR | 기존 표현의 반복과 빈틈을 확인 | 공개 IR, 사업보고서 | 메시지 진단 |
| RFP, 수주·실패 제안서, Win/Loss 분석 | 영업, 프리세일즈 | 고객이 실제로 사는 이유와 거절 이유를 확인 | 공개 RFP, 영업 인터뷰 | B2B 구매 포인트 |
| 경쟁사·대체재 슬로건 및 메시지 감사 | 마케팅, 전략, agency | 유사 문구를 피하고 차별성을 확보 | 경쟁사 홈페이지, 보도자료 | 경쟁 포지션 |
| 브랜드 인지도·연상·선호도 자료 | 마케팅, 홍보 | 현재 인식과 목표 인식의 차이를 확인 | 검색량, 뉴스 키워드, 소셜 반응 | 브랜드 진단 |
| 사용 채널 지도 | 마케팅, 홍보, 영업, HR | 광고, 제안서, IR, 채용, 보도자료에서 같은 문구가 작동하는지 확인 | 웹사이트 메뉴, 홍보물 목록 | 적용 시나리오 |
| 파트너십과 기술 공급망 자료 | 사업개발, 영업, 마케팅 | 기술 실행력과 외부 신뢰를 보강 | 보도자료, 파트너사 홈페이지 | 신뢰 배지 |
| 메시지 테스트 설계 | 마케팅, 조사 agency | 후보를 감이 아니라 데이터로 비교 | 소규모 내부 인터뷰, 영업 설문 | 평가 방법 |
| 임직원 인식 조사와 조직문화 키워드 | HR, 홍보 | 내부에서 쓰기 어려운 문구를 걸러냄 | 채용공고, 임직원 인터뷰 | 내부 캠페인 |

## 6. Low 우선순위 자료

Low 자료는 제안서 디자인, 적용 예시, 캠페인 확장에 쓰는 보조 자료다.

| 요청 자료 | 보유 가능 부서 | 활용 방식 |
|---|---|---|
| 컨택센터, IDC, 솔루션 시연 이미지·영상 | 마케팅, 운영, IT서비스 | 제안서 비주얼과 적용 목업 |
| 상담사 교육자료와 운영 매뉴얼의 비민감 요약 | 운영, HR, 품질관리 | “사람+기술” 메시지 보강 |
| 사내 뉴스레터, 대표 메시지, 내부 행사 키워드 | HR, 홍보 | 내부 공감형 문구 개발 |
| 제품·서비스 명칭 표준과 내부 용어집 | 마케팅, 제품/사업부, 법무 | 국문·영문 표기 통일 |
| 수상·인증·대외 평가 전체 목록 | 홍보, 품질, 보안 | 부록 proof point |

## 7. 후보 슬로건 평가 기준

최종 제안서에서는 후보별 점수를 아래 기준으로 매긴다. 5점 척도로 평가하고, 3점 미만 항목이 있는 후보는 최종 추천에서 제외한다.

| 평가 기준 | 질문 | 필요한 자료 |
|---|---|---|
| 명확성 | 효성ITX가 무엇을 하는 회사인지 바로 이해되는가 | 타깃 페르소나, 고객 언어, 기존 문구 |
| 관련성 | 핵심 고객의 구매 상황과 연결되는가 | RFP, VOC, Category Entry Point |
| 차별성 | 경쟁사와 다른 말인가 | 경쟁사 메시지 감사, 상표 검색 |
| 신뢰성 | 슬로건의 약속을 증명할 자료가 있는가 | 사례, KPI, 인증, SLA |
| 기억성 | 짧고 말하기 쉬우며 검색 혼동이 적은가 | 발음, 약칭, 검색성 검토 |
| 확장성 | 컨택센터, AI, ITO, IDC, 채용, IR에 모두 쓸 수 있는가 | 사업 로드맵, 사용 채널 지도 |
| 법적 안전성 | 우월·최고·AI claim을 실증할 수 있는가 | 법무 검토, 표시광고 실증자료 |
| 내부 채택성 | 구성원이 자연스럽게 쓸 수 있는가 | 임직원 인터뷰, HR 자료 |

## 8. claim 등급 운영

자료 확보 수준에 따라 슬로건과 보조 문구의 강도를 나눠야 한다.

| 등급 | 사용할 수 있는 표현 | 조건 |
|---|---|---|
| Level 1: 공개자료 기반 | “고객 접점”, “IT 서비스”, “AI 솔루션 확장” | 공시와 홈페이지로 확인 가능한 범위 |
| Level 2: 내부자료 기반 | “운영 품질”, “검증된 AICC”, “고객 경험 개선” | 내부 KPI, 사례, 인증 범위 확인 |
| Level 3: 외부검증 기반 | “업계 최고”, “국내 대표”, “가장 신뢰받는” 등 우월 표현 | 독립 조사, 수상, 인증, 비교 근거, 법무 승인 |

현재 단계에서는 Level 1 표현을 기본으로 두고, High 자료 확보 후 Level 2까지 확장하는 것이 안전하다. Level 3 표현은 원칙적으로 쓰지 않는 편이 좋다. 쓰려면 실증자료와 법무 승인이 먼저다.

## 9. 즉시 요청할 자료 패키지

자료 요청은 한 번에 모두 요구하기보다 1차와 2차로 나눈다.

### 1차 요청

- 브랜드 전략, 비전·미션, 중장기 사업 우선순위
- 기존 CI/BI 가이드, 기존 슬로건·캠페인 문구, 금칙어
- 타깃 고객군과 산업군별 수주·매출 비중
- 컨택센터 운영 규모, KPI, SLA, QA 체계
- AICC·RingCloud·xtrmSolution·ITO·IDC 도입 사례
- 보안·품질 인증, 적용 범위, 유효기간
- 상표·법무 검토 기준

### 2차 요청

- VOC, CSAT/NPS, 주요 고객 요구 요약
- RFP, 제안서, Win/Loss 분석
- 경쟁사 메시지 감사
- 브랜드 인지도·연상·선호도 조사
- 사용 채널 지도와 캠페인 적용 범위
- 임직원 인식 조사와 내부 커뮤니케이션 자료

고객명, 계약금액, 개인정보, 민감한 운영 수치는 원자료가 아니어도 됩니다. 익명화 사례, 범위값, 공개 가능한 요약본이면 충분합니다. 자료는 슬로건 후보의 신뢰성, 차별성, 법적 안전성을 검토하는 데만 사용하겠습니다.
